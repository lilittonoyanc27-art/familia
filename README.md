# Familia Adventure — Aprende español jugando

Семейная 3D-игра для изучения испанского языка. В ней четыре героя: **Elena** (мама), **Alejandro** (папа), **Lev** (сын) и **Mira** (дочка). Есть открытый испанский город, 18 мест с интерьерами, симуляторы, блочный мир, клуб настольных игр, школа и семейные миссии.

> ¡Bienvenida, familia! ¡Vamos a aprender español juntos!

## Запуск

Нужен Node.js 20+ (проверено на Node 22).

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию http://localhost:5173). Чтобы зайти с телефона в той же сети Wi-Fi:

```bash
npm run dev -- --host
```

Сборка и тесты:

```bash
npm run build
```

```bash
npm test
```

Готовая сборка лежит в `dist/`. Её можно открыть локально:

```bash
npm run preview
```

## Публикация

**Vercel.** Импортируйте репозиторий на vercel.com. Настройки уже лежат в `vercel.json` (сборка `npm run build`, каталог `dist`). Можно и через CLI:

```bash
npx vercel --prod
```

**Netlify.** Импортируйте репозиторий: `netlify.toml` уже задаёт команду и каталог публикации. Можно и вручную перетащить папку `dist/` на app.netlify.com/drop. Через CLI:

```bash
npx netlify deploy --prod --dir=dist
```

В сборке используются относительные пути (`base: './'`), поэтому она работает и из подкаталога.

## Как устроен язык

- Весь игровой мир, реплики, задания и кнопки написаны по-испански.
- **Клик по любой испанской фразе** открывает карточку: русский перевод, озвучка, медленная озвучка. Если нажать на отдельное слово в карточке, покажется его перевод. Словарь строится автоматически из ~520 слов по темам, служебных слов и всех форм 34 глаголов в пяти временах.
- На кнопках рядом с испанской подписью стоит маленькая кнопка **RU**: она показывает перевод, не нажимая саму кнопку.
- Клик по любому предмету в 3D (холодильник, стул, продукт, животное, блок) озвучивает его название и показывает перевод.
- Озвучка работает через Web Speech API с голосом `es-ES`. Если испанского голоса в системе нет, в «Ajustes» есть подсказка, как его установить.
- Уровни A1, A2 и B1. Уровень повышается автоматически при высокой точности, его можно сменить и вручную в профиле.
- Типы упражнений: перевод в обе стороны, аудирование, выбор реплики, порядок слов, пропуски, спряжение (Presente, Pretérito Perfecto, Indefinido, Imperfecto, Futuro Simple — по уровню) и устный ответ (распознавание речи, если браузер его поддерживает; иначе ответ вводится текстом). При ошибке показывается объяснение на русском.
- У каждого члена семьи свой словарь, история ошибок, повторение трудных заданий, статистика и инвентарь.

## Что есть в игре

**Город** (открытый мир, WASD/стрелки или сенсорный джойстик, камера мышью/пальцем, колесо или щипок для зума). Смена дня и ночи, погода (солнце, облака, дождь), машины и автобусы на светофорах, пешеходы, поезд, самолёты, корабль, море, фоновые звуки. 18 мест: дом, супермаркет, школа, парк, кафе, ресторан, торговый центр, магазин одежды, аптека, банк, детская площадка, кино, библиотека, магазин игрушек, строительный магазин, игровой центр, вокзал, аэропорт и пляж. В каждое здание можно войти: внутри интерактивные предметы с подписями, жители с диалогами и занятия. Остальные члены семьи ходят следом; за любого из них можно переключиться.

**Семейный дом**: двухэтажный, с кухней, гостиной, ванной, гаражом, садом, спальнями и балконом. Здесь можно готовить, завтракать всей семьёй (диалог), собирать рюкзак и чемодан, убирать, звонить по телефону, приглашать гостей и планировать выходные. Купленная мебель появляется в доме.

**Елена**: супермаркет в 3D (список, бюджет, акции, сравнение цен, взвешивание, вопросы продавцу, касса и сдача), кухня (тортилья, паэлья, гаспачо, салат, крокеты, чуррос: выбрать продукты, мыть, резать, смешивать, жарить, подавать), кафе (заказы клиентов, подсчёт суммы), магазин одежды, организация путешествия.

**Александр**: вождение по городу (маршрут с испанскими указаниями, кольцо с номерами съездов, светофоры и штрафы, парковка, поручения), мастерская (стол, стеллаж, будка, ремонт машины, раковины и розетки, строительство дома), семейный бюджет, бытовая техника, банкомат, разговоры в ресторане, банке и по телефону.

**Лев — Lev Craft World**: свой блочный мир с собственными текстурами. Три мира (лес и горы; пустыня и острова открываются в магазине), бесконечная подгрузка чанков, пещеры, деревня с жителями и загадками, лабиринт, спрятанный сундук, река. Можно добывать и ставить блоки, создавать предметы (кирки, топор, лопата, факелы, кирпич, стекло, двери, сундуки, хлеб, табличка города), сажать и собирать пшеницу, кормить животных. 15 миссий, постройки сохраняются отдельно для каждого члена семьи. Дополнительно: гонки с воротами-словами, пенальти, паркур, 3D-лабиринт, поиск клада, математика по-испански. За игры Лев получает доски и кирпичи для своего мира.

**Мира — клуб игр**: шахматы (полные правила: шах, мат, пат, рокировка, взятие на проходе, превращение, троекратное повторение, правило 50 ходов; четыре уровня компьютера, игра вдвоём, подсказка, отмена хода, комментарии на испанском), шашки, «Plaza Mayor» (своё круговое поле: покупка городов, дома, аренда, карточки событий, задания по испанскому за деньги, 2–4 игрока и компьютер), домино, морской бой, крестики-нолики с вопросами, «Поиск пар», игра в слова на поле (своя раскладка бонусов), судоку, пазл, кроссворд, «Колесо букв», «Лестница знаний» (15 вопросов, 3 подсказки), «Угадай слово», логические задачи, детектив, поиск отличий в 3D-комнатах, квест-комната, география.

**Школа**: класс, библиотека, столовая, спортзал, двор и учительская. Есть урок с поднятием руки, математика, география, разговоры с учителями и одноклассниками, родительское собрание для Елены и Александра.

**Jugamos en familia**: шесть миссий, каждый шаг выполняет конкретный член семьи. Ужин, поездка в Испанию, строительство дома, детектив с сундуком, игровой вечер, Новый год.

**Соревнования**: режимы «один», «два», «три», «четыре игрока», «родители против детей», «Елена и Лев против Александра и Миры», «вместе без соревнования». Игры на очки проходят по очереди с передачей устройства, настольные — за одним полем. Есть семейная таблица, командные очки, секундомер, медали, кубки, задания дня и достижения.

**Награды и магазин**: монеты, одежда и головные уборы (видны на 3D-персонаже), машины (используются в вождении и гонках), мебель для дома, материалы для Льва, новые миры.

## Технические детали

- React 19 + TypeScript + Vite, 3D на Three.js (один движок `src/three/stage.tsx` для всех сцен).
- Все модели собраны в коде из примитивов (~250 предметов) и объединены в один меш на предмет, поэтому вызовов отрисовки мало. Персонажи процедурные, с анимацией ходьбы, жестов и речи. Миниатюры предметов отрисовываются из тех же 3D-моделей.
- Физика: столкновения с коробками-препятствиями, ступеньки, прыжки, гравитация; отдельная воксельная физика в блочном мире.
- Каждая игра загружается отдельным чанком только при запуске (`React.lazy`), чанки блочного мира генерируются и выгружаются по мере движения.
- Качество графики: авто/низкое/среднее/высокое (тени, плотность объектов, разрешение). В авто-режиме разрешение снижается само, если кадры идут медленно.
- Пауза (Esc, P или кнопка), полный экран, перезапуск задания, настройки звука и речи.
- Прогресс всех четырёх профилей автоматически сохраняется в `localStorage`; в настройках можно сделать экспорт и импорт в файл.
- Тесты (`npm test`): perft шахматного генератора (стартовая позиция, Kiwipete, позиция 3), мат и пат, ИИ находит мат в 1 ход, правила шашек, единственность решения судоку и логических задач, морской бой, кроссворд, спряжения, перевод по клику, генератор вопросов всех типов и уровней, числа, диалоги, генерация блочного мира, маршруты вождения, связность игр, интерьеров и миссий.

## Ограничения (честно)

- **Мультиплеер только локальный** — на одном устройстве, по очереди или за одним полем. Онлайн-синхронизации между устройствами нет: для неё нужен сервер, а имитировать её я не стал.
- Озвучка зависит от голосов, установленных в системе; распознавание речи работает не во всех браузерах (лучше всего в Chrome). Без него устный ответ вводится текстом.
- Графика стилизованная и процедурная: внешних 3D-моделей и текстур нет. Так всё работает офлайн, но это не фотореализм.
- Названия игр собственные: «Plaza Mayor», «Palabras cruzadas», «La rueda de las letras», «La Escalera del Saber», Lev Craft World. Это игры известных жанров с оригинальным оформлением, а не копии конкретных продуктов.
- Сохранения хранятся в браузере. Если очистить данные сайта, они пропадут — заранее сделайте экспорт в файл.

## Структура

```
src/core      — хранилище и сохранения, речь, звук, словарь перевода, генератор заданий
src/data      — лексика, фразы, глаголы, диалоги, места, интерьеры, магазин, миссии
src/three     — движок сцены, персонажи, модели предметов
src/world     — город и интерьеры
src/games     — все игры (elena / alejandro / lev / mira / common) и общий хост игр
src/ui        — интерфейс, карточка перевода, страницы меню
tests         — автотесты
```
